One pickup line, as if a vending machine were flirting with a passing human,
for the [make.fun bounty](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
"One Line, One Minute: The Vending Machine Pickup Line Contest".

## The line

> Beep! My coils saved the last chocolate bar for you — press B4, insert exact change, and let's call it fate.

108 characters. The machine speaks in the first person, in its own world —
coils, slot B4, exact change — and the punch lands on the last few words.

## How it works

`main.ts` (Node 22) writes exactly that one line to `/output/entry.txt`.
Nothing else is written; the entry is the line, one breath, charming not creepy.
